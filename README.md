BugQuest SDK for Unity
===========

This is the UPM package for the BugQuest SDK for Unity. BugQuest is a lightweight, comprehensive cloud error and crash monitoring solution for Unity games that is free for most developers.

Install it by selecting **Add package from git URL** in the Unity Package Manager:
```
https://github.com/Main-Tank-Software/bugquest-unity.git
```

For more details please see:

[BugQuest Documentation](https://www.bugquest.gg/docs/)

[Install a UPM package from a Git URL](https://docs.unity3d.com/2022.3/Documentation/Manual/upm-ui-giturl.html) in the Unity documentation.
